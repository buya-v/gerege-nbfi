— this branch's parent commit, i.e. the last state of the file that still carried the literal

The 186 KB copy is left out of the commit on purpose: it is a duplicate of a tracked file whose
content is fully determined by a sha already recorded here, and a duplicate of a tracked file is
one more place for a corrected byte to rot (P-80 — "A CORRECTED CARDINAL ROTS IN EVERY PLACE IT
WAS RESTATED"; the same argument applies to a restated FILE).
