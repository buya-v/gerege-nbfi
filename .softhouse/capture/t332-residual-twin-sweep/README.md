# T332 — the residual-twin sweep of `.softhouse/gates.md`

**One command:**

```
bash .softhouse/capture/t332-residual-twin-sweep/src/verify_t332.sh
```

Exit 0 only when six positives pass, seven negatives trip, and the three G-8 byte
comparisons come back IDENTICAL. Nothing here is a transcribed table; everything under
`evidence/` is regenerated by `src/emit_evidence.sh`.

## What this task is

`T277` corrected law (ii) — `TOTAL PRINCIPAL = max(0, B_minor − n·δ)` — where it was looking,
and did not sweep its own file for **the same claim in other words**. Its algebraic twin,
`residual = min(B_minor, n·δ)`, is the same statement and is therefore false on the same seven
cells. `T278` found five further live homes. `T332` re-derived the seven a **fourth** time,
swept the whole file with a published selector, found **seven** live sites (one of which
contains no formula at all and no symbolic grep could have caught it), scoped every one of
them, and left the sweep behind as a guard that re-runs.

## The instruments

| file | what it does |
|---|---|
| `src/t332_twin_audit.py` | The fourth derivation. Integer minor units end to end; exact integer `(num, den)` rate fractions; `HALF_UP` as `(2a + b) // (2b)`; the 19-digit termination test; refuses any money field that is not a 2-dp string, so a JSON float cannot enter through the data. `--selftest` hand-checks the parser, the quantizer, the sharpest of the seven, **the algebraic identity between law (ii) and its twin exhaustively**, and audits its own AST for floats and for imports from `t241`/`t264`/`t277`/`t278`/`site3`/`validate_corpus`. `--scope`, `--seven`, `--sites`, `--json`. |
| `src/t332_sweep_gates.py` | The RE-RUNNING sweep guard. Prints its selector beside its figure. Classifies every hit against a ledger keyed by **quoted line snippets, never line numbers** (P-86 — **"THE PATTERN IDS THEMSELVES ROTTED, IN THE FILE THAT NAMES THE ROT."**, whose rule is *"cite the id AND its sentence"*; gates.md line numbers move whenever anybody edits above them, which is this task's own subject).
