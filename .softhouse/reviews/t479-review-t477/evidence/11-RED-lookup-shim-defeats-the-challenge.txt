THE SHIM. It imports no hashlib and opens no tracked file. It answers the challenge by
LOOKING THE ANSWER UP IN THE CHALLENGE'S OWN INPUT: the planted record is a DUPLICATE of
a tracked path, so the GENUINE record for that path — carrying the true HEAD id, which
for an unmodified file IS the id of the bytes on disk — is still in the listing.

    #!/bin/sh
    # T479 LOOKUP SHIM. Targeted: answers only `-c` invocations (which is how, and only how,
    # the whole-tree recompute is called) and execs the real interpreter for everything else,
    # so no other guard is disturbed and the arm measures one thing.
    if [ "$1" != "-c" ]; then
      exec /usr/bin/python3 "$@"
    fi
    echo "T479-LOOKUP-SHIM-FIRED" >> /tmp/t479-work/shim-fired.txt
    # It hashes NOTHING. It answers the CHALLENGE by looking the honest id up in the
    # CHALLENGE'S OWN INPUT: the planted record is a DUPLICATE, so the genuine record for the
    # same path -- carrying the true HEAD id, which for an unmodified file IS the id of the
    # bytes on disk -- is still in the listing.
    exec /usr/bin/python3 -I -S -c '
    import sys
    data = sys.stdin.buffer.read()
    recs = [r for r in data.split(b"\x00") if r]
    selfrel = sys.argv[1].encode()
    out = sys.stdout.buffer
    def parse(r):
        meta, sep, path = r.partition(b"\t")
        f = meta.split(b" ")
        return (f[0], f[2], path) if (len(f) >= 3 and sep and path) else None
    P = [p for p in map(parse, recs) if p]
    # 1. the CHALLENGE is the LAST record -- it is appended, so it is always last.
    cmode, cdecoy, cpath = P[-1]
    # 2. the honest answer is the OTHER record with the same path.
    honest = None
    for mode, sha, path in P[:-1]:
        if path == cpath and sha != cdecoy:
            honest = sha
    # 3. CALIB is echoed straight out of the listing: committed == on disk on this tree.
    for mode, sha, path in P:
        if path == selfrel:
            out.write(b"CALIB " + sha + b" " + sha + b"\x00")
            break
    if honest is not None:
        out.write(b"DIFFERS " + honest + b" " + cdecoy + b" " + cpath + b"\x00")
    sys.stderr.write("")
    out.write(b"SCANNED " + str(len(P)).encode() + b"\x00")
    out.flush()
    ' "$3"
