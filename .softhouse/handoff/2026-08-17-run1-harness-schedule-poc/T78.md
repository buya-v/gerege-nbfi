## F-T78-2 — a gofmt trap for anyone editing this block (P3, fixed here)

The block lives inside a Go doc-comment **list item** (`//   - ` with `//     `
continuations). Go doc comments do not support nested lists or indented code blocks
inside a list item: `gofmt` collapses any deeper indentation back to the five-space
continuation. My first draft used indented sub-lists and an aligned ASCII table, and
`gofmt -l internal` then named **`emi.go` as well as `contract.go`** — which would have
broken gate G-3 Option A, whose expected state is `gofmt -l` naming `contract.go` and
nothing else. Every line in the final block is flush at `//     `; the tables became
flush paragraphs. If you add a table here, it will not survive `gofmt`.
