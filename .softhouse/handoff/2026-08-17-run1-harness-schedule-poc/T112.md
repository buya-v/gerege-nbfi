### What this sweep could NOT have found

State it plainly, because a sweep's reach is part of its result:

- **It is lexical.** A restatement that expresses "family A is everywhere in the rate axis" without
  any of the strings above — for example "the rate is not a factor", "no rate escapes it", or a
  table cell carrying only `12` — would not have matched. I read the whole G-8 section end to end
  as a second pass, which is the only defence against that, and it is a human-reliability defence,
  not a mechanical one.
- **It covers this repository only.** Any restatement in `tasks.json` task notes written by the
  driver, in a fire manifest, in a review on another branch, or in an unmerged worker branch is
  outside it. `tasks.json` in particular quotes the false sentence in its T101 and T112 task notes;
  those are quoting it *as the defect*, so they are correct in context, and I did not edit
  `tasks.json` (it is the orchestrator's file).
- **It cannot find a restatement that is true of one family and false of the other without naming
  either.** That is the P-23 shape, and only sentence-by-sentence reading catches it. T101 built
  the 56-row table that does this; I did not rebuild it, I checked the three rows it failed and
  spot-read the rest.
- **It says nothing about correctness of the numbers.** It is a consistency sweep. The numbers were
  re-derived separately, above.

## The 18-vs-22 ruling and its float cause

**Adopted: the count is 22.** T101 adjudicated by recomputing from the raw captures in exact
rational arithmetic and ruled for T100's 22 — T83's 330 cells 330 held / 0 refuted; T84's 342 cells
**320 held / 22 refuted / 0 exact ties at all**.

**The cause is now in the gate text, not just the count.** The four disputed cells are T84's own
`T84-TIE-R600p0-N{108,120,150,200}-B1`. Its `.softhouse/reviews/T84-evidence/prediction.json` stores
`BtimesA` for them as the IEEE-754 double `0.5` — I re-read the literal in the committed file
[VERIFIED: `{"B": 1, "BtimesA": 0.5, "n": 108, "predictedFails": false}`]. In exact rational
arithmetic `B·a − ½` is strictly **positive** there and of order 1e-20 (`+4.799e-20` at n = 108,
T101's figure — `[UNVERIFIED by me]`, I did not recompute the residual myself), so the closed form
predicts CLEAN and the measured FAIL refutes it. Double precision cannot resolve a residual that
small, so four strict inequalities were read as exact ties and dropped.

The gate now says why that distinction matters: it is the difference between *"two agents counted
differently"* and *"a float in an analysis script put a wrong number into the document the product
owner reads"*. The no-floating-point rule visibly bound the port, the schema, the vectors and the
fixtures; it did not visibly bind **analysis and prediction scripts**, and this is what that gap
cost — the script graded nothing, and its float still reached this gate. **That belongs in
`patterns.md`**; see Follow-ups (I did not edit `patterns.md` — the postmortem section is the
driver's).

## Scope discipline — the 53 sentences I did not regress

**three** failures of content (F-1, F-2, F-3) plus five P3 nits. The rule every row is graded

measured over.**

How I avoided regressing the other 53:

  replacements, each asserted to match **exactly once** or abort). No paragraph was rewritten
  wholesale, no section was regenerated, and no sentence outside the nine was touched. A
  fail-on-ambiguity replacement is the mechanical guard against collateral edits.
- **Every replacement I wrote carries both scope limbs itself.** F-1's new text names family A and
  names the rate set it was measured over. F-7's names the shape *and* the swept principal range
  `3..6 minor`. F-8's names T83's terms as an explicit eight-element set rather than a range. F-4's

  everything T83, T84 and T100 swept" and keeps 331 attributed to T84's narrower set rather than
  silently overwriting it. F-2's attaches each bound to its grid.
- **I added no new conclusion about the oracle's behaviour.** Every sentence I added is either a
  correction of a stated number, a citation, or a statement about *this repository's* files
  (`grade.go`, a committed JSON). The gate's substantive claims are still T83's, T84's, T100's and
  T101's.
- **Second pass:** I read the whole section start to finish after editing, checking that each of
  the twelve `600.0` sites attributes that rate to family B, that no sentence acquired an unscoped

**What I did not do:** I did not rebuild T101's 56-row table. If a fourth reviewer wants
