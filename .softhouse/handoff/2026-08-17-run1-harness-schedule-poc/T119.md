## Ruling — the exit-2 conflation

**Accept the channel. The required edit is in the driver.**

Exit 2 is not the oracle code — it already carries eight-plus unusable conditions including `ZERO VECTORS FOUND`. Every alternative is worse and I re-derived each from source: `Summary.Errored` increments inside the grading loop (`grade.go:318-319`), so it needs grading to have run; `LoadError` reaches exit 2 **without** the early return, so the inflated counts still print — that is exactly M3, and M3 is red; a fifth code contradicts a four-code table restated in three files.

The disambiguator already exists and is always printed: `conformance.sh:296` emits `probe = up|down` **before** the binary runs, so `probe = up` + `exit 2` cannot be an outage. What is unsafe is the driver's written rule — `.claude/skills/softhouse-program/SKILL.md:108-109` keys parking on the event and then says *"Only exit 2 is the oracle-is-down stop condition"*, inviting a driver to key on the bare code. T110 just added a new way to reach exit 2 with `probe = up`. This is the exit-3 failure (`conformance.sh:38-52`) reappearing one level up, and the remedy is the same one that worked there.

> **Raise as its own task:** SKILL.md must read **`exit 2 AND probe ≠ up` → park on an oracle reason; `exit 2 AND probe = up` → the harness or corpus is defective, park nothing on the oracle.**

Also for the follow-up: the new refusal is **not** in `conformance.sh --prove`'s proof set. T110 was correctly kept out of that file this fire; add `expect 2 "a duplicate case_id in the store"` when it is free.

## Ruling — the census question

**Yes, a census refusal is right. Charset `[A-Za-z0-9._-]` is sound. Two corrections to the brief.**

1. **The two enumerations already disagree on the CLEAN store** — `find` returns 49, `LoadStore` loads 47, because `PIN.json` and `capabilities.json` sit at the root. A naive equal-counts census is red on day one. The predicate must carry an **explicit, short** exemption list (`PIN.json`, `capabilities.json`, `README.md`).

It closes F-T110-5 outright and F-T110-4's realistic form with no `x/text` dependency. Constraint for the implementer: the charset rule is a property of **one file** → raise it as a `LoadError`, not through `DuplicateCaseIDs`, and drive it red on a scratch store carrying `P-00-café`.
