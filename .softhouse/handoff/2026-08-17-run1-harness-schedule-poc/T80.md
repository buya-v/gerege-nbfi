## P0-A — the canary, and how I proved it now bites

**The defect.** `grep -qF '"principal": 1162502.5'` is a *substring* test, so it matches
`1162502.55`. And `1162502.55 × 0.018 = 20925.0459`, which is **not** a half-minor-unit tie: it
rounds to `20925.05` under HALF_UP *and* HALF_EVEN. The script then printed `sha256 $creqsha`
without ever comparing it. T77 drove that to *ALL PRECONDITIONS HOLD, exit 0* on `gerege`, and to
*PASS effective rounding mode canary (= HALF_UP)* on the HALF_EVEN `default` tenant.

**The fix has two independently-sourced operands.** Operand (a) is `shasum -a 256 "$CANARY_REQ"`,
computed at run time over the bytes that are about to be POSTed. Operand (b) is the literal
`PIN_CANARY_SHA256` in the recipe. A caller controls only (a). T77's own formulation — *a check has
two operands and a caller controls both; a literal digest has neither* — is the property kept.

**Proved by running T77's exact exploit against my script.** My mutation is byte-for-byte T77's:
the computed digest of the mutated request is **`13ce2f4f21a1ad568b080b859682b9e995aac97712e00fcf44c6fc177d6b9ca5`**,
the same `13ce2f4f…` T77's review reports [VERIFIED: `t80/out/attack-2a-mutated-canary-gerege-sh.txt`
vs T77's review text]. Result now:

* on **`gerege`**: exit **1**, exactly **1** FAIL — `canary request DIGEST MISMATCH — computed
  sha256 '13ce2f4f…' … pinned sha256 is '2a6621be…' … THE CANARY WAS NOT SENT and the effective
  rounding mode is UNPROVEN`. **Both digests named**, as required
  [VERIFIED: `t80/out/attack-2a-mutated-canary-gerege-sh.txt`, EXIT=1].
* on **`default`** (HALF_EVEN): exit **1**, **5** FAIL, and the sentence
  *"PASS effective rounding mode canary"* is **absent from the file**
  [VERIFIED: `t80/out/attack-2b-mutated-canary-default-sh.txt`; `grep` finds no such line].

**A standing assertion, not just a transcript.** `t80/forbidden-sentence.sh` scans every committed
T80 transcript and fails if that PASS sentence ever appears without a *passing digest-pin line* on
tenant `gerege`. **27 files scanned (24 attack transcripts + 3 happy-path precondition transcripts), 0 violations, exit 0**
[VERIFIED: `t80/out/forbidden-sentence.txt`]. This is the check T85 should re-run first.

## P0-B — the abort, and how I proved it now fires

**The defect had two halves and both are closed.**

*Half one — the signal never reached the gate.* `bad()` writes to stderr; the old caller `tee`'d only
stdout, so `grep -c '^  FAIL'` on that file was structurally always `0` and `exit 1` at the old `:31`
was dead code. Now: `… > "$O/preconditions.txt" 2>&1 || prestatus=$?`, then abort if
`prestatus != 0` **or** `prefails != 0`.

*Half two — the capture was mis-filed.* `O` was the literal `out/recapture-gerege` while `TENANT` was
a variable. Now `O` derives from `$TENANT`, an explicit override must be named for the tenant, and a
stamp guards re-use.

**Proved by running T77's exact command:**

```
$ TENANT=default sh t36/recapture.sh
### tenant 'default'  ->  output directory …/t36/out/recapture-default
  … 17 PASS, 5 FAIL (Asia/Kolkata; rounding-mode='6'; MySQL-era schema_connection_parameters;
    JVM initialized 'default' at HALF_EVEN; canary HTTP 404 — the mode in force was never established)
PRECONDITIONS BREACHED: 5. DO NOT CAPTURE.
ABORT: preconditions breached — exit status 1, 5 FAIL line(s) … NOTHING WAS CAPTURED.
EXIT=1
```
[VERIFIED: `t80/out/attack-1a-wrong-tenant-sh.txt`]

* **Zero captures taken.** `t36/out/recapture-default/` contains exactly two files —
  `CAPTURED-FROM-TENANT` (contents: `default`) and `preconditions.txt`. **No `B-0*-raw.json`**
  [VERIFIED: `ls -la`]. Both are committed as evidence.
* **Nothing written into any `gerege`-named directory.** The eight files in
  `t36/out/recapture-gerege/` have identical sha256s before and after the whole task
  [VERIFIED: `t80/out/BEFORE-digests-…txt` vs `AFTER-digests-…txt`, digest columns diff clean;
  and `git status --porcelain` shows **no modified tracked file** after the attack runs].
* **The mis-filing attack is refused before the preconditions even run.**
  `TENANT=default RECAPTURE_OUT=…/t36/out/recapture-gerege sh t36/recapture.sh` →
  `ABORT: output directory … is not named for tenant 'default' … refusing to write 'default' bytes
  into a directory called 'recapture-gerege'.` EXIT=1
  [VERIFIED: `t80/out/attack-1b-wrong-tenant-into-gerege-dir-sh.txt`].
* **The stamp is failable too**, demonstrated on a directory whose name says `default` but whose
