## Findings

My own probes: **249 cells** (sha `3900a204…cbf17`) and **93 cells** (sha `47611b04…23313`), a
harness derived from `CaptureT83.java` with the case list replaced, both passing T83's full
precondition set including both rig calibrations. **My prediction was committed as `e6d6a47` before
either probe was built or run**, and both evidence commits are its children.

Domain check: DEC-1 §3.1 and `contract.go` bound neither the annual rate nor `NumberOfRepayments` —
*"Rates, principals, terms and dates … are graded by **sampling**"*. The port refused **0 of 344**
cells and the harness **admitted** my vector and graded **761 cells**. Everything below is in-domain.

- **P0-1 — G-8's rewritten definition is refuted.** `gates.md` now says G-8 *"is precisely: the
  outstanding-balance column is stale … **while its principal column and its own totals are right**"*.
  **False.** At **600.0 % p.a. / MNT 0.01 / n ≥ 104** (22 measured cells, n = 104…121 contiguous plus
  150 and 200) the principal column **sums to 0.00 against a 0.01 disbursement**,
  `totalPrincipalAmount` reads `0.00`, and the final row carries `interest 0.01`. The driver's own
  test — *"if it ever fails to sum, the reframing is wrong and G-8 is the broader finding"* — is met.
  And by the driver's own discriminator it is **not a stale memo**: forced memo recompute leaves the
  balance at 0.01 on 3 of 3 (family 1 control at 3.6 %/n=360 moves 1.09 → 0.00; three clean controls
  unmoved). **The Go port reproduces all 22 cell for cell — 0 divergent cells.**

- **P0-2 — "`invariant_exemptions` is inert, so option (a) needs a port change" is refuted as a
  general claim.** Demonstrated with the **real `conformance.Run` and the real port** on a scratch
  store, vector transcribed by T83's own `build()`: without exemption **761 graded cells, 0 cell
  diffs, FAIL** with `principal_portions_sum_to_disbursed` and `principal_amortizes_to_zero`
  **VIOLATED**; with the exemption, **PASS, parityPass 1, 0 violations**. **Zero port change.** T83's
  premise — *"without any exemption all six invariants already HOLD because they read the port's
  output, which amortizes"* — does not hold where the port does not amortize. The gate's recorded
  "cheap option" **does** exist; it exists on the part of the region T83 did not sample.

- **P1-3 — "Every principal in the region is below MNT 0.25 / far below one MNT" is refuted.**
  Measured largest failing principals, each bracketed on both sides: **MNT 1.09** at 3.6 % / n = 360
  (an ordinary 30-year monthly term), **MNT 1.76** at 0.12 % / n = 360, **MNT 2.91** at 0.12 %
  / n = 600 — 11.6× the stated bound. The region grows with the term (`≈ n/2` minor units as the rate
  falls); it is not capped at the rounding floor. The practical conclusion (no realistic loan *amount*
  is affected) survives; the stated bound does not.

- **P1-4 — the closed form is falsified outside the sampled grid: 18 measured refutations**, all at
  600.0 % / B = 1 / n ≥ 104, exactly where `B·a − 0.5` falls through the precision-19 floor
  (n = 103 gap +3.6e-19 clean → n = 104 gap +2.4e-19 **fails**). It held on 324 of my 342 cells and on
  every `RP`/`FAR`/`RATE`/`TERM`/`LONG` cell. **T83 was right to label it a hypothesis and this
  vindicates that call** — but `gates.md` should now record that it has been *tested and falsified*
  there, or the next reader will read 106/106 as licence.

- **P2-5** — `grade.go:487-497` citation is imprecise: `CheckInvariants` runs **first** at `:488`; the
  `len(diffs) > 0` early-return at `:489-493` short-circuits the **outcome**, not the computation.

- **P2-6** — provenance: the `:400`/`:1180`/`:1210` chain was **first stated by T75** (its review §5),
