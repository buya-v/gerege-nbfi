## 2. The fix — one shared module, because the cause was a fix landing in one file

New: **`.softhouse/capture/lib/attest_gate.py`**. Imported by all three sidecars. It is
deliberately *not* inlined three times, since the proximate cause of this defect was a correction
that reached one file and not its forks (P-21/P-26).

`assert_effective_rounding_mode(...)` is called **immediately after the canary is observed and
before any capture is taken**, so a run that cannot establish the mode spends no requests on the
oracle and leaves no bodies of unknown provenance behind. It refuses, **exit 4**, on any of:

1. the environment trying to supply the answer (`CANARY_EXPECT`, `ATTEST_SKIP_MODE_GATE`, …) —
   this is T76's hole, pre-closed;
2. the canary request not matching its **pinned digest** — without this the gate would be the very
   tautology T77 exploited: a request that is not an exact tie answers `20925.05` under *both*
   modes, so grading it certifies nothing;
3. canary HTTP ≠ 200, or a body whose period-1 interest cannot be read — *unobserved* must not
   read as *passed*;
4. the observed tie answer ≠ `20925.05` (and it says so explicitly when it is `20925.04`);
5. `MoneyHelper.PRECISION` ≠ 19; 6. `c_configuration.rounding-mode` ≠ 4; 7. the JVM's own init
   line ≠ `HALF_UP`.

`assert_attestation_is_verified(att, key)` runs **immediately before `json.dump`** and grades the
*document* by reading back the very fields about to be serialised. **No `attestation.json`
claiming a verdict it did not verify can be written.**

Also fixed, found while wiring: **`t36/attest.py` and `charges/bin/attest.py` parsed the canary's
period-1 interest through a binary float** (`json.loads(...)` with no `parse_float=str`) — a float
in a monetary path, inside the check that guards the rounding mode. Both now use
`parse_float=str`. `attest-t40.py` already did.

### Sibling claims (brief item 5) — both gated, neither exempted

* **`matches_ratified_production_setting`** — the configuration twin of the behavioural canary,
  and the same shape. Its three conjuncts are now gate clauses 5–7, and the assembled field is
  re-read before writing: not-`True` (including `None`) refuses.
* **`byte_identical_to_prior_issue`** (`attest-t40.py`) / **`matches_committed_corpus_bytes`**
  (both `attest.py`) — same shape: computed, printed, never compared. `False` now refuses. `None`
  does **not** — an absence of a prior capture is not agreement with one — but it is printed as an
  explicit count so it can never read as a passing comparison.

### Also changed, and why

* **`attest-t40.py` gains `ATTEST_OUT` / `ATTEST_TASK` / `ATTEST_BRANCH`**, adopting T76's fix to
  the file it was forked from. Without it there was no way to drive this rig green without
  overwriting T40's committed capture set — *"re-running a generator over the artefacts it
  produced last fire destroys the very record a reviewer diffs against."* When `ATTEST_OUT` is
  used the directory must be named for the tenant (T80's rule).
* **`attest-t40.py`'s `preconditions_result`** transcript path was hard-coded to
  `out/attested/preconditions.txt`; it is now derived from `OUT`.
* **`charges/bin/attest.py` gains a header stating what it is** — see §6.
