### THE ARGUMENT — refuse or report, argued against T9-F1b as instructed

I did **not** weaken the refusal wholesale, and I did not conclude that refusing is
wrong. **`DECORATION` and `NOT-EVALUABLE` are still exit 2, on T222's own T9-F1b
argument, unchanged.** What changed is which outcomes that argument reaches.

T9-F1b (`admitDivergentCell`) refuses **a self-contradiction inside one file**: the
same vector says *"this cell diverges"* and *"this cell was never observed"*. Three
reasons it does not reach the withdrawn-cells case, in order of weight:

1. **The two claims are not contradictory.** An exemption's claim is about **the
   oracle's behaviour**; an `unrecorded_fields` entry is about **what the capture
   transcribed**. Both can be true at once. *"The record does not say"* is not
   *"the record says no"*, and T222 read one as the other.

2. **Concluding UNGROUNDED from UNOBSERVED is finding T58-N2, one level up.**
   T58-N2's ruling is that a cell nobody observed must be **declared and not
   asserted upon, in either direction** — the false GREEN (an invariant agreeing
   with the stand-in it was handed) *and* the false RED. `invariants.go` obeys
   that. The grounding check did not: it read "no observation" and returned a
   verdict **against** the exemption.

3. **The refusal had no correct remedy and prescribed a false one.** Grounding
   judged `RecordedSchedule` **+ that vector's placeholders**; the exemption acts
   at grading time on the schedule **the implementation returned**, and a real
   port computes every cell and implements no `PlaceholderReporter`
   (`registry.go`'s `PlaceholderCells` doc — *"This is the ONLY implementation …
   and it must stay that way"*; `grade.go`'s conditional type assertion). So the
   printed remedy — *"drop the exemption and let the harness report the assertion
   as NOT RUN, which is what it is"* — was true **in self-test replay mode only**
   and **false in the mode that matters**. A guard whose prescribed remedy breaks
   the mode it exists to protect must not be an exit-2 refusal.

**T220-N1's actual complaint is still enforced, three ways**, because the danger
was always the *count* being quoted as evidence:
* an undetermined exemption is **not counted as GROUNDED** — the census
  partitions `Declared` into `Grounded + Undetermined + Ungrounded`, asserted;
* it is **named in the run output every run**, with the withdrawn cells;
* the corpus-wide pin asserts **`Undetermined == 0`** today, so the first one to
  arrive is a deliberate edit a reviewer sees in the same commit as the vector
  that brought it.

The **claim-needs-evidence** half of T9-F1b is properly closed by T222's own
follow-up **F-4** (require a capture citation on an exemption's reason) — which
applies to **all four committed exemptions**, whose reasons are uncited prose
today, not only to the ones a capture gap made uncheckable. Still open; see
Follow-ups.
