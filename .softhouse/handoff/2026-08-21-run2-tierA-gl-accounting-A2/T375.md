## 3. THE FIX — two tests on what git TRACKS, not on what the path resolves to

**THE GENERALISATION, which is the durable part and is written into the guard's header:** four
separate repairs in this class have now tightened **how a path is resolved**, and the hole was
never in the resolution. **A PATH IS NOT A FILE.** Every test in this guard reads its subject
*through the filesystem* while git tracks something else. Both new tests therefore ask git.

1. **A SYMLINK — member or witness — IS REFUSED.** What git tracks at that path is the *target
   path string*, while `grep` grades the *dereferenced* file's bytes: **the bytes graded are not
   the bytes committed at that path**, and the target may not be in the repository at all. That
   is the identical objection this direction already printed for an untracked witness. The member
   check runs **first, before any other test touches the member**, and is **deliberately not
   waivable by a `REACHED-BY` row** — the row would be read through the link too.
2. **A WITNESS WHOSE TRACKED BLOB IS THE MEMBER'S TRACKED BLOB IS REFUSED.** Comparing object ids
   compares what is **committed**, not what is on this host, and catches hard link and copy with
   one test.

**Two tests and not one, because neither subsumes the other** — a symlink's blob is the target
path string, so it does **not** collide with the member's blob and no content compare can catch
it; a hard link and a copy are ordinary regular files, so no mode check can catch them.

**MEASURED BEFORE THE CHANGE, so this is a calibration and not a hope:** `git ls-files -s
.softhouse/guards` shows **no symlink and no two identical blobs**, so neither test refuses
anything standing today [VERIFIED: my own run; and arm `T375-09`, pass 1's legitimate
`./`-spelled witness, stays ACCEPTED].

**THE CENSUS LINE GAINED A FIELD AND THE PLACEMENT IS LOAD-BEARING.** It now ends
`... invoked-by-nothing=0 symlink-members=0`. A symlink member is **not** "invoked by nothing" —
it is not gradeable at all — and folding a second finding into an existing cardinal is how a
census stops showing what it found. **It is appended at the END** because every arm in the T323,
T358 and T375 drives matches that line by a substring ending at `invoked-by-nothing=N`; a new
