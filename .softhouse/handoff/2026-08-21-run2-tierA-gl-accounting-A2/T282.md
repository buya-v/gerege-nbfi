## 1. Which side is authoritative, and why

**`.softhouse/patterns.md` is authoritative.** Not because it is the obvious answer — because it is the
only candidate that satisfies the two properties an authority needs here:

1. **It is the site of DEFINITION; every other site is a RESTATEMENT.** `patterns.md` is where a `P-n` is
   introduced with its rule text under it. `T259`, `T262`, `lint_failopen_t259.py` and `RESUME.md` *use*
   ids they did not define. When a definition and a restatement disagree, the restatement is the thing
   that drifted — this is **`P-80`** (*A CORRECTED CARDINAL ROTS IN EVERY PLACE IT WAS RESTATED; the count
   is the same defect as the line number*) stated as a rule of evidence rather than a rule of hygiene.
2. **The renumbering event is recorded on `patterns.md`'s side, with its cause.** `patterns.md:2760`
   carries the merge note: the six patterns *"were renumbered on landing"* from `P-78`…`P-83` to
   `P-79`…`P-84` because a cloud fire had already published a rival `P-78`. So `patterns.md` holds the
   **post-correction** numbering *and the reason it changed*; the citing sites hold the **pre-correction**
   numbering *and no reason at all*. One side can explain the disagreement. That side wins.

**The counter-argument, stated so it is not left implicit:** the merged citations are older and more
numerous, and "the majority is right" is not a silly position when the artefacts are evidence. It fails
here for a specific reason — **the drifted sites are not independent witnesses.** `P-86` records that a
single driver propagated one off-by-one into **all ten worker prompts of one fire**. Ninety copies of one
mistake is one mistake, and counting them as ninety is the error `P-67` names (*a figure certified EXACT
whose denominator was never measured*).

**Consequence, and it is the one that made this task tractable:** because `patterns.md` is authoritative
and the merged prose is evidence, the remedy for a drifted citation in someone else's file is **an errata
entry, not an edit** — which is also what `T316` established when it refused to repoint a forward-reference
inside committed evidence and was right to.

## 5. The checker, and why this predicate

`.softhouse/capture/t282-pnumber-drift/bin/check-pnumber-citations.py`

> **A `P-n` citation carrying rule text must carry text matching the rule `patterns.md` defines under THAT
> number, and no other.** The **SENTENCE**, never the id.

**Why not the obvious guard, DEMONSTRATED and not asserted.** Both recorded instances were harmless for one
reason: every prompt wrote the **full rule text** beside the id, so the number was decoration and the
sentence carried the instruction. The mechanical consequence is that a guard asking *"is `P-n` defined?"*
**returns PASS on every instance of this defect** — every drifted citation names an id that exists.
Stage 2 of the RED drive runs exactly that predicate over the identical bytes:

```
EXISTENCE-ONLY CHECKER: register holds 95 ids; 3 citations examined
EXISTENCE-ONLY CHECKER: undefined citations = 0  []
EXISTENCE-ONLY CHECKER: VERDICT PASS
```

…while the sentence-matching predicate reports three findings and exits 1 on the same file.

**Fail-closed direction is stated, not assumed.** DIRECTIVE files (`patterns.md`, `RESUME.md`,
`conformance.sh`, `CLAUDE.md`, `.claude/skills/**`, `.softhouse/bin|guards/**`) **fail closed** — they
instruct workers not yet born and are lawfully repairable in place. Committed evidence, ratified ADRs and
orchestrator-owned files are **report-only**, because failing closed there would create pressure to edit
exactly the bytes the evidence rules forbid editing, and would block every graded run on prose nobody may
lawfully repair.

### Three defects the checker had, all found by RUNNING it at real bytes

1. **THE ERRATUM WAS A SHIELD — a fail-open whose blast radius was the whole population.**
   Cross-reference suppression exempts a citation when the better-matching rule's own body names the cited
   id. **`P-86` is an erratum: its body names `P-78`…`P-84` precisely in order to say those citations are
   wrong.** On the real drifted line from `RULES-failopen.md:17`, `P-86` and `P-81` tied at 6, the tie broke
   toward the higher id, `P-86` won, was suppressed *because it names `P-80`* — and the finding vanished.
   **The correction was absorbing the defect it documented.** Fixed: a suppressed winner may be skipped but
   may never **end** the search. This also **refuted the checker's own docstring**, which claimed rare-token
   scoring caught that site; it never reached the report.
2. **The fatal margin was fitted to nothing.** `tasks.json:2427` scored `mine=1, best=9, margin=8` — missing
   a 9-point margin **by one**. Margin was only ever a proxy for *"the sentence does not state the rule it
   cites at all"*, so that is now measured directly (`FATAL_MAX_CITED_SCORE = 1`) — also **stricter** where
   false positives live.
3. **A markdown table cell is a citation boundary.** `patterns.md:785` ends *"…invisible to BSD grep
   (P-33)"* — a **correct** citation of `P-33` (*a tool claim is a claim about a binary, a version, a
   LOCALE, an invocation and an input shape*). The extractor walked backwards out of that cell into the
   row's first cell, *"Money is integer minor units, no floating point"*, and scored it against `P-25`.
   **Fatal, and wrong.**

Removing the shield then cost a fourth fix — **use is not mention**. `patterns.md:2866` *quotes* the wrong
ids with the correction on the same line. Resolved with `P-86`'s own remedy: if the id the gloss actually
matches is already beside the citation, the text is **self-correcting** and no reader can be misdirected.

# T282 — P-NUMBER CITATION DRIFT.  The predicate is the SENTENCE, never the id:
# a guard asking only "is P-n defined?" returns PASS on every recorded instance
# of this defect, because every drifted citation names an id that EXISTS.

# ---------------------------------------------------------------------------
guard_pnumber_citations() {
  local chk="$REPO_ROOT/.softhouse/capture/t282-pnumber-drift/bin/check-pnumber-citations.py"
  if [ ! -f "$chk" ]; then
    warn "conformance: THE P-NUMBER CITATION CHECKER IS ABSENT: $chk"
    warn "conformance: it is wired into this guard, so its absence is a REFUSAL and never a pass."
    return 1
  fi
  local out rc
  out="$(mktemp "${TMPDIR:-/tmp}/conformance-pnumber.XXXXXXXXXX")" || return 1

  # SELFTEST FIRST. A checker whose predicate has stopped discriminating would
  # report a clean tree in exactly the same words as a clean tree (P-22: a
  # control that cannot fail is worse than none, because it is believed).
  if ! ( cd "$REPO_ROOT" && python3 "$chk" --selftest ) >"$out" 2>&1; then
    warn "conformance: the P-number citation checker FAILED ITS OWN SELFTEST. Its verdict on this"
    warn "conformance: tree is worthless until that is fixed."
    LC_ALL=C sed -n '1,20p' "$out" >&2
    rm -f "$out"; return 1
  fi

  ( cd "$REPO_ROOT" && python3 "$chk" ) >"$out" 2>&1
  rc=$?

  # PRESENCE BEFORE VALUE (P-84): a verdict line that was never PRINTED is a
  # crash, and it must never be read as a clean run.
  if ! LC_ALL=C grep -aqE '^PNUMBER-CITATIONS: VERDICT ' "$out"; then
    warn "conformance: the P-number citation checker printed NO VERDICT line (exit $rc). It did not"
    warn "conformance: run, or did not finish. Silence here reads exactly like a clean register."
    LC_ALL=C sed -n '1,20p' "$out" >&2
    rm -f "$out"; return 1
  fi
  if [ "$rc" -ne 0 ] && [ "$rc" -ne 1 ]; then
    warn "conformance: the P-number citation checker exited $rc, which is neither clean (0) nor"
    warn "conformance: violations (1). 3 is its own refusal-to-run; anything else is a crash."
    LC_ALL=C sed -n '1,20p' "$out" >&2
    rm -f "$out"; return 1
  fi

  LC_ALL=C grep -aE '^PNUMBER-CITATIONS: (register|sites|skipped|declared|  )' "$out" \
    | while IFS= read -r l; do say "$l"; done
  if [ "$rc" -ne 0 ]; then
    warn "conformance: A CITED P-NUMBER CARRIES A RULE SENTENCE THAT patterns.md DEFINES UNDER A"
    warn "conformance: DIFFERENT NUMBER, in a DIRECTIVE file — a file that instructs future workers."
    LC_ALL=C grep -aE '^PNUMBER-CITATIONS: (FATAL|VERDICT)' "$out" >&2
    rm -f "$out"; return 1
  fi
  say "conformance:   P-number citations: VERDICT PASS (evidence-zone drift is REPORTED, never"
  say "conformance:   fatal, and is corrected FORWARD in the patterns.md errata — never in place)."
  rm -f "$out"
  return 0
}

### The population is a moving target, and the merge proved it twice
