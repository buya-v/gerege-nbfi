## 2. What I actually changed: the instruction, not the instruments

`.softhouse/reference-oracle.md:616` prescribed `. /Users/buv/gerege-nbfi/.softhouse/bin/go-env.sh`. That is
the site that **manufactures** bucket 2 — every one of those 60 pastes came from a worker reading this line.
This is T245's shape exactly: inventory corrected, instruction left behind.

### The design constraint was the whole difficulty: do not write a convention that asks a future fire to remember something

The obvious fix — write a better sentence — fails that constraint. So the activation line now lives between
machine-readable markers and **is extracted and executed by the drive that grades it**:

```
<!-- T256-ACTIVATION-LINE:BEGIN ... -->
. "$(git rev-parse --show-toplevel)/.softhouse/bin/go-env.sh"
<!-- T256-ACTIVATION-LINE:END -->
```

Put a host path back between those markers and the drive goes **red off-host, in a transcript, quoting the
offending line**. Nobody has to remember the convention; the thing that checks it runs it.

The line **composes with `go-env.sh` rather than duplicating it**. `go-env.sh` remains the seam that finds the
toolchain — it resolves the *shared* install through `git rev-parse --git-common-dir` so a worktree gets the
main checkout's one toolchain and one module cache. The activation line does not re-implement any of that.
**I did not touch `go-env.sh` at all** (T272 holds it).

**Convergent evidence that the form is right, found by accident:** `T238`'s `sweeplib.sh` documents its own
usage as `. "$(git rev-parse --show-toplevel)/.softhouse/capture/t238-failopen/instruments/sweeplib.sh"` —
the same self-locating shape, reached independently, for the stated reason *"Never hard-code an absolute
worktree path: the worktree that produced the evidence is deleted within days and the path outlives it."*

### Also changed, same defect class, same document

`reference-oracle.md:153` prescribed `/Users/buv/gerege-nbfi/.softhouse/bin/build-oracle-image.sh` — a repo
instrument addressed by absolute Mac path. Now the same self-locating form.

### What survives, deliberately

The `GOROOT` row still contains the Mac path, **relabelled as an observation**: *"On the local fire's host

recorded installation fact. The census section that lists these is titled **HOST-PATH SITES**, and its rule is
stated: each surviving site must be an **observation**, never an **instruction**.

**Reference-oracle (Fineract) connection facts are untouched and verified intact:** tenant `gerege`,
`fineract_gerege` on **PostgreSQL 18.3**, `docker-compose-postgresql.yml`, pinned commit **`426a23544`**,
