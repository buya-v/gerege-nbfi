## F-1 (MAJOR) — the rule REFUSES a legitimate exemption, and it costs the whole vector

**The grounding check judges a different schedule from the one the exemption acts
on.**

* Grounding evaluates the invariant against `RecordedSchedule(v)` **plus that
  vector's `PlaceholderCells`** (`exemption.go:152,163`).
* Grading evaluates it against **the schedule the implementation returned, with
  placeholders EMPTY** — a real port computes every cell and implements no
  `PlaceholderReporter`, which `registry.go:93-95` states as a design rule
  (`grade.go:699-704`).

So one legitimate `unrecorded_fields` entry can make the invariant *unassertable
on the record* while it remains *fully assertable, and violated, on the port's
output* — where the exemption is the only thing standing between the corpus and a
false RED.

**Measured.** Store copy of `T116-G8-FAMB-N104`, one repayment row (period 5)
with `principal_minor` withdrawn and blanked. Its **committed, today-GROUNDED**
`principal_portions_sum_to_disbursed` exemption is untouched.

```
GROUNDING VIEW (recorded schedule + this vector's placeholders):
    N/A — "principal advanced cannot be compared with principal repaid: 1 row(s)
           carry a principal nobody observed…"
PORT-MODE VIEW (same schedule, placeholders empty):
    VIOLATED — "principal advanced 1 minor units, principal repaid 0, difference -1"

HARNESS VERDICT: INADMISSIBLE, exit 2
    parity vectors  46 -> 45
    graded cells    7884 -> 7837
    kills named     106 money -> 104 money
    this vector now contributes 0 graded cells
```

That is the failure mode the brief said T222 could not have found by
construction: **the refusal silently keeps a legitimate vector out**, and it takes
its ~47 graded cells and 2 named money kills with it.

**And the refusal's prescribed remedy is FALSE.** `exemption.go:229-230` tells the
author to *"drop the exemption and let the harness report the assertion as NOT
RUN, which is what it is."* NOT RUN is what it is **in self-test replay mode
only**. In port mode the same invariant reports **VIOLATED** — measured above.
Following the shipped advice turns a correct vector into a red run.

**Honesty scoping.** Whether a real Path A capture would ever omit a *repayment*
row's principal is **[UNVERIFIED]** — no vector does today, and I did not capture
one. What is verified is that the schema explicitly supports it, that the store
already carries `unrecorded_fields` on 29+ disbursement rows, and that
`registry.go:118-124` deliberately keeps `outstanding_principal_minor` on a
DISBURSEMENT row *off* the contract-fixed list precisely so that withdrawing it
produces a placeholder. The channel is designed in, not hypothetical.

**Ask.** Either evaluate grounding on the port-mode view (placeholders empty), or
classify `HOLD`/`N/A`-with-`NotAsserted` as a **third outcome that is reported,
not refused**. Not a reviewer's call to make — see the scope note at the end.
