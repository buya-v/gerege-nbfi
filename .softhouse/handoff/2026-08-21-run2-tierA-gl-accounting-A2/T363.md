### `t305` / `t327` — the decision, argued

**T359's "both rigs fail closed on their next run" is true only of a STANDALONE invocation.** The
supported entry point is `run-all.sh`, whose step 0 does `rm -rf "$OUT"` and then **regenerates**
`out/STANDING-baseline.txt` from the live oracle before `capture.sh` / `down.sh` read it [VERIFIED:
`t305/throwaway/run-all.sh:29,33` then `:53`; `t327/throwaway/run-all.sh:45,50` then `:70`].

**I did not repair, delete, or re-baseline them.**

- **Delete** — rejected: `run-all.sh` is the *admissibility argument* for LDG-05/06/07, captured on an
  instance that no longer exists. Deleting it destroys the evidence that makes promoted vectors
  admissible.
- **Retype the cardinals** — rejected: `STANDING-baseline.txt` is a **capture output** timestamped
  `2026-08-27T15:38:48Z`, not a maintained pin. Retyping it makes the file disagree with the run that
  produced it — a forged witness that rots again on the next probe.
- **Convert the pin to a derived query** — rejected as stated: `$now` is *already* a live `SELECT`. The
  invariant the scripts want is "the standing oracle did not move **because of me**", a delta across the
  run, not equality with a file of unknown age.
- **RECOMMENDED: fix the AGE, not the number** — refuse a baseline older than the current run
  (`[ "$BASE" -nt "$RUNMARK" ]`), which is fail-closed, never rots, types no cardinal, and turns a silent
  wrong answer into a named refusal. Exact patch shape in `CASUALTIES.md` § A. **Not applied — outside
  this task's write grant.**
