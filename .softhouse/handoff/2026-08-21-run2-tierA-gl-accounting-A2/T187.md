## Changes Made

[VERIFIED: `.softhouse/reviews/t41-probe/t187-census-output.txt`, "GUARDED yes (shared)" on all 25]

What each hardened file gets, all of it the guard's and none of it re-implemented:

- atomic `tempfile.mkstemp(dir=<the target's own directory>)` → `fsync` → `os.replace`, with
  `st_dev` compared so the replace is really atomic;
- sha256 content gates on **both** sides — the target must equal `BEFORE_SHA256` before a byte is
  produced, and the candidate text must equal `AFTER_SHA256` before anything is moved into place;
- default-deny argv authorisation: no default target, a per-script literal `--authorise=` token,
  targets refused inside the repository working tree, under a directory named `adr`/`contract`,
  named like the protected artefact, or (for the contract scripts) ending in `.go` — **and no
  override that reaches a ratified or frozen artefact**;
- no bare `assert` anywhere (`python3 -O` strips them); every refusal is an explicit exit.
[VERIFIED: the census reads the shared guard by FOLLOWING THE IMPORT and checks all nine
properties — `t187-census-output.txt`, "SHARED GUARD (followed by import) … sha256 0448e508…"]

## Census: follows imports or superseded?

**Superseded, and I wrote the successor.** Both halves of the answer:

- **T167's sibling census** reads guards from each file's OWN ast. It would score all 25 hardened
  files here as `try 0 / atomic False` — UNGUARDED — for exactly the reason T178 recorded. I did
  **not** rely on it.
- **T178's `t178-guard-census.py` does resolve delegation** — the right fix — but its family is
  `glob(os.path.join(SCAN, "t47_edit_*.py"))`, which matches **none** of `edit*.py` /
  `edit_go*.py`. Its `--scan=` flag changes the directory, not the glob. Widening it means editing
  `.softhouse/reviews/t47-probe/`, which is **outside T187's scope guard**.
  [VERIFIED: `t178-guard-census.py:232`]
- So `t187-census.py` **supersedes T167's for this directory and reuses T178's principle**: a file
  is guarded when it delegates every write to the shared guard, and the census **follows the import
  and reads the shared guard itself**, checking nine properties (`os.replace`, `mkstemp(dir=`,
  `fsync`, `st_dev`, both content gates, refusal of the artefact itself, refusal of in-repo
  targets, no bare `assert`) and printing the guard's own sha256. A census that credited delegation
  without reading the delegate would be P-22 again.
- **P-56 rule 1 honoured:** the census walks exactly one directory, never recurses, and **prints**
  that exclusion. It cannot reach `.claude/worktrees/`.
- **P-40 honoured:** non-members are named, not dropped; an unresolvable write target is a failure,
  not a skip. The one exemption (`t187-redgreen.py`, which writes into a `tempfile.mkdtemp` tree)
  is **named, printed, and conditional** — the exemption is refused unless the file both contains
  `tempfile.mkdtemp(` and has no write site resolving to a protected path.

## Follow-ups

Outside T187's scope guard — recorded, not actioned, no diff:

1. **`t178-guard-census.py` is hard-wired to `glob("t47_edit_*.py")` (`:232`).** Its `--scan=` flag
   moves the directory but not the family, so pointing it at any other probe directory silently
   inspects **zero files** and exits 0 — a census that inspects nothing must be an error, not a
   pass (P-22's own rule). Suggest a `--glob=` flag, or defaulting the family to `*.py` minus a
   printed exclusion list.
2. **Nothing runs either census automatically.** `t187-census.py` and `t178-guard-census.py` are
   standing tripwires that no harness invokes. A pre-flight hook running every `t*-census.py` under
   `.softhouse/reviews/` and failing the run on a non-zero exit would make this class of defect
   impossible to reintroduce. Given three separate fires have now found unguarded rewriters
   (T167 → T178 → T187), the pattern is that the *next* probe directory will have them too.
3. **The wider family has not been swept.** T187 measured only `t41-probe/`. Other
   `.softhouse/reviews/*/` directories may hold the same shape; a repo-wide sweep under the R5 rule
   (excluding `.claude/worktrees/`, per P-56 rule 2) is the obvious next task.
4. **A latent hazard in any future mechanical hardening of this family.** T187's transformer
   filtered *lines*, and a line inside a triple-quoted replacement string that happened to strip to
   `import sys` or `s = io.open(` would have been silently deleted. That did not happen here — the
   IDENT check proves it, 25/25 — but the safe shape is AST-based surgery, and the IDENT check
   should be run by anyone repeating this on another directory.
5. **`edit15.py` does not exist.** T41's numbering skips it. Recorded so a future reader does not
   go looking for a missing file.
