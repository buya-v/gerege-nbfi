### Is *"does the pending correction change what a conformant implementation must DO?"* the right test?

**It is the right test, and it is stated too narrowly. Both halves matter.**

Right, because `CLAUDE.md` locates the gate on the **obligation**, not on the document: *"a ratified DEC-n
still cannot be amended by an agent without raising a gate"*, and *"the frozen adapter contract is the
boundary."* What a gate on a contract protects is the **shape a port must conform to**. If nothing a
conformant implementation must do changes, then no work done in the interval can be invalidated by the
correction, and there is nothing for the gate to protect. That is a real principle, not a convenience.

Too narrow, because it is purely **normative** and the harm `T246` actually identified is **epistemic**.
`T246`'s own words, which I quote because they are the sharpest statement of the risk and they are *not*
the driver's framing: the banner *"tells the reader the opposite of the truth in the safe-sounding
direction — a reader who believes the ledger is ungraded will not look for what the grading does and does
not cover, which is exactly the misreading §8.3 exists to prevent."*
[VERIFIED: `.softhouse/reviews/t246-dec2-rev6/REVIEW.md`, F-T246-1]

So the honest test is a **conjunction**, and the driver applied only the first conjunct:

1. Does the pending correction move any obligation, field, rounding rule, or graded cell? — **NO.**
2. Would a worker who reads the **UNCORRECTED** document build something different, or fail to consult
   evidence it should have consulted? — **YES, plausibly.** That does not close the gate over the work.
   It creates a **briefing obligation**, which is cheaper than parking a tier and which the driver did
   not record. See `F-3`.

### Engaging the strongest argument AGAINST, rather than noting it

> *The G-11 prohibition existed because an unratified SHAPE must not be built on — and a reader is
> instructed to read DEC-2's banner before any other sentence, so a false banner is not obviously a
> document a port may safely be built against.*

I take this seriously and I think it fails, for a reason the driver did not give: **the direction of the
falsehood.**

- Under **G-11**, DEC-2 was UNRATIFIED. The thing under negotiation was the **normative shape**. Go
  written against it could be invalidated wholesale by ratification, and — worse — creates facts on the
  ground that bias the ratification it is supposed to be waiting for. The prohibition is not about the
  document being *wrong*; it is about the document being *not yet binding*. **That is a categorically
  different reason from "a sentence in it is false."**
- Under **G-14**, DEC-2 rev 6 **is** ratified. Every normative clause is settled. The defect is a
  **measured evidential claim that went stale**: the banner says *"NOTHING GRADES THIS CONTEXT AT ALL"*
  when the harness in fact grades **4 ledger parity vectors, 2 oracle-refusal vectors, 21 money cells**
  on every run. [VERIFIED: my own BAR, `bar-output.txt:357,362,521-523`]

Now the decisive point. **The banner errs pessimistically.** It understates what is graded. A worker
misled by it believes *"I have no oracle safety net here, and no green run is evidence."* The truth is
*"part of this is graded and the rest is not."* A worker operating on the false belief is **more**
cautious than reality warrants about the graded part, not less — and is exactly as cautious as reality
warrants about the ungraded part, which is most of it. **There is no direction in which the falsehood
licenses a worker to write Go that a corrected banner would forbid**, because the corrected banner
forbids nothing the false one permits; it *permits more*, by revealing that a safety net exists.

The residual harm is real and is `T246`'s: a worker who thinks nothing is graded never reads the coverage
boundary, and so does not learn what the vectors *do* and *do not* cover. That produces **worse-informed
work**, not **wrongly-shaped work**. Wrongly-shaped work is what a CONTRACT gate exists to prevent.
Worse-informed work is what a briefing prevents. The remedy is a brief, not a prohibition — and the
driver got the conclusion right while omitting the remedy (`F-3`).

## Who may write `blocks`? (proposal only)

**Nobody is checked. That is the answer, and it is the whole finding.** `blocks` is free text in a JSON
file that any worker with write access to `program.json` can widen into a permission slip, and the
resolver prints it under a header that reads as a finding. `F-6`/`A19` demonstrates it end to end. This
is `P-45`'s fail-open class and `CLAUDE.md`'s *"Do not let an agent decide these"* has **no mechanical
counterpart at all** in this path.

**Proposed enforcement, in priority order. I did NOT implement any of it** — `ready-tasks.py`,
`program.json` and `conformance.sh` are all on my do-not-edit list.

1. **Type gate, fail-CLOSED** (this is `F-1`'s micro-fix, promoted to a rule). `blocks` is a non-empty
   `str` or the key is absent. Anything else → treat as ABSENT, print the conservative fallback, and print
   `MALFORMED`. Closes `A04`/`A06`/`A07`/`A09`/`A10`/`A11`/`A12`/`A13`.

2. **Three-field quorum, and the resolver already has the lookup it needs.** Print `blocks` as SCOPE only
   if `blocks`, `blocks_decided_by` and `blocks_reviewed_by` are all non-empty strings **and**
   `blocks_reviewed_by` names a task id that is TERMINAL in `tasks.json` or the run archive.
   `ready-tasks.py`'s existing `load()` already returns exactly that `(cur, arch)` pair, so this costs no
   new machinery. Otherwise — missing, non-terminal, or containing `PENDING` — print the scope under
   **`UNREVIEWED SCOPE — DO NOT ACT ON THIS`** *and additionally* print the conservative fallback.
   **The key property: an unreviewed scope never SUPPRESSES the prohibition, it only annotates it.**
   Note this makes **G-14's own entry print UNREVIEWED today**, which is correct and which the driver
   itself would want, since its `blocks_reviewed_by` literally reads `T249 (PENDING)`.

3. **The decider may not be the reviewer.** Reject loudly where `blocks_decided_by` and
   `blocks_reviewed_by` denote the same actor. This is the `T245`/`T249` rule, mechanised — currently the
   program relies on the driver voluntarily filing a task against itself, which is admirable and is not a
   control.

4. **Shelf life (P-69).** Require `blocks_measured_at: "<sha>"`. Print
   `STALE — this scope was decided at <sha>, N commits ago; re-derive before acting` whenever
   `HEAD != sha`. `F-5`/`A25` is the standing proof that this is needed: G-12's `blocks` is false at HEAD
   and nothing anywhere says so.

5. **Separate the ARGUMENT from the SCOPE** (`F-2`). `blocks` = one short scope sentence.
   `blocks_rationale` or `gates.md` = the reasoning, **not printed by the resolver**. A tool must not read
   a 1,713-character brief aloud as its finding.

6. **Fix the selector fail-CLOSED** (`F-4`): missing/unknown `class` ⇒ treated as CONTRACT; open/closed by
   enumerated token, not substring.
