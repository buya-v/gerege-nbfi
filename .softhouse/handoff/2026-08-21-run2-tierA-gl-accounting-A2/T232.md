### NEW — the second mechanism: `git grep -E` does not implement `\b` at all

T227 named the right-anchor (Mechanism 1) and stopped there. Re-measuring forced me to pick an engine,
and the pick is load-bearing. Discriminator, on a line reading `…to any balance column exists`:

```
$ git grep -c -E  'balance column'  90c21d6 -- .softhouse/guards/ledgerguard/main.go   ->  14
$ git grep -c -E '\balance column'  90c21d6 -- .softhouse/guards/ledgerguard/main.go   ->  14
$ git grep -c -P '\balance column'  90c21d6 -- .softhouse/guards/ledgerguard/main.go   ->   0
$ git grep -c -E  'Command'         90c21d6 -- .softhouse/guards/ledgerguard/main.go   ->   1
$ git grep -c -E '\bCommand'        90c21d6 -- .softhouse/guards/ledgerguard/main.go   ->   0
```
