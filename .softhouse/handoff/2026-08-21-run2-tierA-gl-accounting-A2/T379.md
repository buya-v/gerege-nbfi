## The four residual defects I found

- **R1 (inherited).** The two `$ARCHIVE` greps in `sel()` still discard their status. Driven: with
  only `$ARCHIVE` broken, a selector that **hit** reports `LIVE: 0` at **exit 0**, `did_not_run=0`
  — F2's exact shape one step downstream, and the `exit 0` contract ("both are MEASUREMENTS") is
  not honoured there [`out/R4-THIRD-STATUS-DRIVE.txt` § X]. `$ARCHIVE` is the line T371 just
  edited, so this is live territory.
- **R2 (NEW, in T371's own code, and the one I nearly rejected on).** The **anti-calibration is
  itself fail-open**: `2>/dev/null` plus the pipe into `awk` discard `git grep`'s status, so a
  search that **errors** yields `n=0` and the guard prints
  `SWEEP CALIBRATE-: PASS — known negative matched 0 times across the tracked corpus`,
  `calibration=yes`, exit 0 — **byte-identical to the control run on the unmodified instrument**
  [`instruments/t379-anticalibration-drive.sh` → `out/R7-ANTICALIBRATION-DRIVE.txt`]. The positive
  arm has the same construction but fails *safe*. **Bounded:** an engine broken enough to error on
  `-- .softhouse/` also errors on all sixteen selectors, so the run exits **4**, loudly
  inadmissible.
- **R3 (inherited, but with live exposure).** Both calibrations use `-F`; **13 of 16 selectors use
  `-E`**, and the header's stated justification is a `-E` hazard. **T238's finding still reproduces
  on this host, measured by me today:** `git grep -E '\bmain\b'` and `git grep -E 'bmainb'` both
  return **97** hits. A mis-parsed `-E` selector returns rc 1 and prints `MEASURED ZERO` — a
  negative it did not measure, which is the invariant the repair is named after. *Mitigating:* the
  header **states** this blind spot, which is the honest kind of tripwire (`patterns.md:661`).
- **R4 (cosmetic).** `2>&1` folds stderr into the hit set on **every** path including `rc = 0`, so
  a warning counts as a hit; on `rc = 1` the folded stderr is discarded unprinted.

**The rest of the exit contract IS honoured**, checked by reading every path the drives do not
exercise (no work tree → 2; zero tracked files → 2, correctly a `P-35` denominator error;
`sel()` before `calibrate()` → refuses without searching; `SWEEP_RC` accumulated by assignment,
never inherited from a pipeline; `4` never reset by a later `0`).
