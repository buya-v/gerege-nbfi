### What each hardened script now enforces

1. **Atomic write.** `tempfile.mkstemp(dir=<the target's OWN directory>)` — same directory, hence same
   filesystem by construction, **and** `st_dev` compared — then `fsync`, then `os.replace`. The target is
   never opened for writing. No trap is used and none is needed (P-48 rule 4); an interruption leaves the
   whole old file or the whole new one, **including under `SIGKILL`**, which no handler could catch.
2. **sha256 gate on both sides.** The target must equal `BEFORE_SHA256` (else exit 3, nothing written) and
   the candidate text must equal `AFTER_SHA256` (else exit 4, nothing written).
   **This is what actually closes the bypass**: neither `49dc8923…` (the ratified ADR) nor `0db73d4a…`
   (the frozen contract) is any script's `BEFORE_SHA256`, so no run can reach either artefact's current
   contents even with every other guard stripped. Case R8 measures exactly that: a scratch copy of the
   **current** artefact is refused with exit 3, untouched, for all eight.
3. **Default-deny argv authorisation.** No default target; `--target=` mandatory; the target must be outside
   the repo working tree, not under a directory named `adr` (ADR scripts) / `contract` (the contract script),
   not named like the protected artefact, and — for `t47_edit_7.py` — **not a `.go` file at all**, because
   G-3 forbids even `gofmt -w` on `contract.go`. A per-script `--authorise=` token is required, argv-only and
   never an env var. **There is no override that reaches a ratified or frozen artefact.**
4. **No bare `assert` anywhere** in the guard or the eight scripts; `rep`'s anchor check is an explicit
   `if`/exit. Proven by running the GREEN case under `python3 -O` (case R11, 8/8 pass).

### Design decision recorded: one shared guard, not eight inline copies

T167 inlined the guard in `t47_edit_1.py`. Eight inline copies would be **P-27** ("two copies of a claim is
one claim and one time bomb") multiplied by eight, and a defect found in the guard would have to be corrected
in eight places — this pipeline's most reliable failure (P-12/P-21). The trade-off, stated so a reviewer can
weigh it rather than discover it: the guard is no longer textually visible in the file that performs the
write, and an import can fail. **It fails CLOSED** — case R14 deletes `t178_guard.py` and measures exit 1
with nothing written, 8/8 — and each caller inserts its **own** directory at the front of `sys.path` so the
module cannot be shadowed from the cwd or `PYTHONPATH`.

**`t47_edit_1.py` was deliberately NOT converted.** T167's inline version is already correct and already
reviewed; rewriting it to import the shared module would have put a merged, ratified fix back in play for no
measured benefit.

## Pattern candidates for patterns.md

*(`patterns.md` is held by another worker this fire; these are candidates, not edits.)*

- **A guard that is FACTORED OUT stops being visible to any guard-detector that reads one file.** T178 moved
  eight inline guards into one shared module for the right reason (P-27: eight copies is one claim and seven
  time bombs) and **immediately made T167's sibling census score all eight as UNGUARDED**. This is P-48 and
  P-49 arriving together: the census was correct when written, T178's change moved what it measures, and that
  movement is **invisible in T178's own diff**. *Rule: when you refactor the thing a guard inspects, re-run
  that guard and fix or supersede it in the same change — a guard's blast radius is not in the guard's diff,
  and a guard's INPUT SHAPE is part of its specification.*
- **The strongest control on an unauthorised rewriter is a CONTENT gate, not a path gate.** Path policy
  (outside the repo, not under `adr/`, not named like the artefact) is defeasible by a copy, a symlink, a
  rename, or a second checkout. A pinned `BEFORE_SHA256` is not: if the live artefact's bytes are not the
  pinned pre-edit bytes, the script cannot touch it from anywhere, under any name, in any tree. *Rule: gate
  destructive tooling on WHAT the target is, not on WHERE it is; use the path policy as defence in depth.*
- **"Inert" is a property of today's text and it decays silently.** Seven of eight scripts were inert only
  because an anchor had been reworded; two were **one restored paragraph** from live, and six still had an
  anchor present exactly once. A later revision that restores a phrase re-arms them, and nothing would report
  it. *Rule: never let "the anchors don't match any more" stand as the control. Harden it or delete it.*
- **A prover run from a copy of the thing it is proving can test the copy's environment instead of the
  real one.** T178's R5 passed a real-repo path straight through, exit 0, because the post-fix script under
  test was a copy in a scratch tree and the containment check is computed from **the script's own location**.
  P-22 inside the prover. *Rule: exercise the fix at its REAL path; use copies only for cases that must mutate
  the fix (tamper, delete-the-guard), and say which cases those are.*
- **The brief's population is a claim.** T178 was told "nine". Measuring found **27** scripts writing to a
  protected artefact, **25 outside the named directory**, and **two more live bypasses**. The first task
  (T167) was told "one". *Rule: a remediation task's first act is to measure the population itself, from the
  defect's SHAPE rather than from the list it was handed — and to publish the sweep's limits.*
