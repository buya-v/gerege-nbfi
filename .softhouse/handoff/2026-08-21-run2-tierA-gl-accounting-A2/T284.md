## 2. What "FROZEN" turned out to bind, and which repair that permitted

**T114's standing ruling**, in the words this program keeps restating
(`.softhouse/capture/audit-t44/analysis/T207/RULING-float-derived-predicate.md:247`):

> *"Anything that produced COMMITTED EVIDENCE is superseded by a scratch copy, NEVER edited in
> place."*

It binds the **bytes** of the script and of the evidence it produced. All three sites are
caught by it, and in each case the committed evidence **includes the verify transcripts
themselves** — `evidence/redB/arm-*/verify.out|err` (127 files under `t250-tenant-attestation/`)
and `evidence/redB/a*/*.vout|verr` (265 files under `reviews/t261-tenant-attestation/`). Editing
either script would silently change what those transcripts are a transcript *of*.

**So the repair is an explicit, justified re-freeze — NOT a rewrite of the frozen bytes, and
NOT at a caller (there is no caller: all three are run by hand).** Concretely:

1. each site is **declared** with its schema scope and the reason, in a pin a program grades;
2. each site's coverage is carried by a **successor** (the T207/T175 supersession shape);
3. a **notice** sits in each frozen directory, so the reader who is about to run the script
   meets the decision where they are, not in a handoff;
4. the pin **fails** if any frozen file's digest moves, if a class changes, if a successor
   disappears, or if a notice is deleted.

**Declared scope extension:** two files were added *outside* `files_hint` —
`t250-tenant-attestation/instruments/SCHEMA2-STATUS.md` and
`reviews/t261-tenant-attestation/instruments/SCHEMA2-STATUS.md`. Purely additive, zero bytes of
anything pre-existing changed, both pinned as `required_files`. Taken deliberately because a
decision recorded only in a handoff is `P-45` one layer out — **a guard that only works when
someone remembers to read it enforces nothing.** Flagged here for the reviewer to overrule if
they disagree.

## 4. What makes it bite — the call-site registry

`instruments/10-callsite-registry.py` + `instruments/callsite_registry.json`. It enumerates
every `verify` call site in the tracked tree via `git ls-files -z` (no `grep`, no `rg`, no
`git grep -E`), classifies each by the response artefacts it presents
(`SCHEMA2_COMPLETE` / `REQUEST_ONLY` / `PARTIAL` / `INDIRECT`), and grades against the pin.
**Default-deny in six directions**, and **REFUSES (exit 2)** — never "clean" — on a missing pin,
an empty corpus, an unreadable source, or a failed calibration.

Current measurement:

```
  corpus: 14 file(s) carrying 25 `verify` invocation(s)
    INDIRECT          2
    REQUEST_ONLY      12
    SCHEMA2_COMPLETE  11
  pin: 14 declared site(s)
callsite-registry: PASS -- 14 call site(s), all declared, all classes as pinned,
                   4 frozen file(s) byte-identical.
```

**The guard caught its own author.** The first run after the red drive became a tracked file
went **red on `C0` and `Z0`**: `30-red-drive.sh:148` holds a `printf` that plants a rogue
`verify` line into a throwaway clone, and the classifier read the fixture string as a call
site. Two ways out were available: teach the detector a "that's only a fixture" heuristic, or
**declare the line**. Declaring it, because a detector with a not-really-a-call-site rule is a
detector with a place to hide — and this program only narrowed the fail-open linter's
equivalent rule *after measuring the false positives first*. The declaration is in the pin with
that reasoning.

**Two of my own defects, kept because they are the point.** (i) Four tamper heredocs in the site
2 successor were written `open(p,"w").write(open(p).read()…)`, which **truncates before it
reads**. Arms A5–A8 scored `CAUGHT rc=2` on *"sidecar does not begin with
attestation-derivation:"* — a green score for the wrong reason, caught only by reading the
messages under it. (ii) The red drive's reason-printing `sed` used `\|` in a BRE, which BSD sed
reads as a literal, so every arm printed a green tick with **no evidence beneath it**. Both are
fixed, and both are the same defect this task grades in site 3.

## 7. The exact wiring line — NOT applied

`conformance.sh` is partitioned to other tasks this fire. Whoever holds it next, in
`run_guards()`, next to `guard_no_fail_open_instruments`:

```sh
  guard_verify_callsite_registry      || failed=1
```

and the function, with **no pipeline anywhere in it** (P-57: piping the guard's output into
`while read` discards its exit status, which is the fail-open this guard exists to prevent):

```sh
guard_verify_callsite_registry() {
  local out rc=0
  out="$(mktemp "${TMPDIR:-/tmp}/callsites.XXXXXX")" || return 1
  python3 "$REPO_ROOT/.softhouse/capture/t284-schema2-callsites/instruments/10-callsite-registry.py" \
      >"$out" 2>&1 || rc=$?
  LC_ALL=C sed 's/^/conformance: /' "$out"
  rm -f "$out"
  if [ "$rc" -eq 0 ]; then return 0; fi
  if [ "$rc" -eq 2 ]; then
    warn "conformance: the verify call-site registry REFUSED (exit 2): no verdict is available"
    warn "conformance: about which call sites are correctly schema-scoped. This is NOT a pass."
    return 1
  fi
  warn "conformance: the verify call-site registry FAILED (exit $rc). A \`wire_attestation.py"
  warn "conformance: verify\` call site was added, deleted, re-classed, or a FROZEN instrument"
  warn "conformance: was edited in place. The pin is"
  warn "conformance:   .softhouse/capture/t284-schema2-callsites/instruments/callsite_registry.json"
  return 1
}
```

**HARD, and the discriminator P-84 requires.** A failure prints `callsite-registry: FAIL — N
finding(s)` followed by named `* ` bullets, **preceded by the census block** (`corpus: N file(s)
carrying M invocation(s)`). A refusal prints `callsite-registry REFUSING:` and **no census**.
An oracle outage prints the probe line with `down`. **Census lines and no probe line ⇒ a guard
failed. Neither ⇒ the harness died earlier.** Cheap and deterministic: it asks a question about
the repository, never about the oracle, so it cannot park vector work.

**Until that line exists, this registry is itself an unwired guard — the exact shape it was
built to close — and nobody may cite it as an enforced control.** Stated here so it cannot be
over-read.

  the refusal fires on *"a body artefact was supplied but the request record carries no
