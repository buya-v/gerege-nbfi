**S1 — no literal survives, and no redundant equality test was bolted on.** The brief allowed
keeping a literal if a disagreement were made to *fail the bar*. It was measured unnecessary
and actively harmful: `diff -u` compares the two **sorted files for CONTENT**, and content
equality implies length equality, so `$m` and `$p` cannot differ on any path that reaches the
pass line. A literal kept "for safety" would then be **the only thing in the guard capable of
disagreeing with the pin** — the defect, not the safeguard. An added `[ "$m" -ne "$p" ]`
refusal would be a branch **no reachable input can enter**, i.e. a guard nobody can ever watch
fail, which is `P-45`'s point turned inside out (*"a guard that only works when someone
remembers to run it enforces nothing"* — an unexercised guard enforces nothing, and a branch
with no reachable input is unexercisable by construction). What **is** checked is the
derivation: a cardinal that does not derive **refuses** rather than falling back to `0`, because
a fallback zero is `P-35`'s vacuous pass arriving through the front door.

**S2 — repaired although it was accurate.** `pinned at 11` was correct on the day it was swept.
It was repaired because this exact figure **has already rotted**: `T248` moved the frontier
9→10, `T252` moved it 10→11, and `T252` found `t243-wiring/instruments/20-failopen-red-drive.sh`
still asserting `frontier == pinned (all 9 rows, by path)` in two live `want_line` checks.
Waiting for the third move before deriving buys one cycle.

**S3 — a cardinal about a collection in a file this script does not own.** `33` is right today
(`ledgerguard/main.go:745-777`) and is one edit to `main.go` away from being wrong on every run.
The paragraph above it already said so in its own words: *"Recount it before quoting it; every
figure in this paragraph has now been stale once."* Read from **source, not from the binary's
output** — the sentence claims how big the const *is*, not how much of it the head's pass-path
filter let through; counting what got printed would make the figure agree with a filter that
dropped half the block. **The derivation does NOT change the guard's exit code, and that is a
decision:** the graded property here is the ledger walk's verdict, and turning a rename of a
documentation const into `EXIT 2` for the whole bar would make the run's colour depend on a doc
string. A failed derivation prints the words **`line count NOT DERIVABLE`** where the number
would be, plus a `warn` on stderr. Both arms driven — §4.

**S5 — the count was deleted, not corrected.** `"the seventeen rows below"` was a **second rot
site for the same cardinal**, spelled in words, so the numeric sweep that found `pinned at 17`
**could not see it**, and it was wrong by one against an 18-row pin. It is nine lines above the
list; a restatement that cannot be wrong is a restatement that is not there.

**T293's correction bracket is left standing and annotated,** not deleted: it is the record of
how the defect was found. Only its present tense is now false, and the appended `[T300 CLOSES
T293 F5]` sentence is what makes that visible.
